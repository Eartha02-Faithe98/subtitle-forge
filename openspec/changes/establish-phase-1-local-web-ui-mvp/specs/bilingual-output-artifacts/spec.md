## Purpose

Defines the complete set of Phase 1 transcript, subtitle, summary, and download artifacts and the timestamp invariants users depend on.

## ADDED Requirements

### Requirement: Completed jobs expose the required artifact set
A completed job SHALL expose an English timestamped transcript, a Traditional Chinese timestamped transcript, an English SRT, a Traditional Chinese SRT, a bilingual SRT, an English summary, and a Traditional Chinese summary.

#### Scenario: Inspect a completed result
- **WHEN** a job reaches `COMPLETED`
- **THEN** its result manifest contains exactly one available entry for each of the seven required Phase 1 artifacts

#### Scenario: Required output cannot be generated
- **WHEN** any required artifact is missing or invalid
- **THEN** the job does not transition to `COMPLETED`

### Requirement: Transcript artifacts retain source timestamps
English and Traditional Chinese transcript artifacts SHALL present ordered segments with timestamps derived from the original media, and corresponding bilingual segments MUST share the same start and end times.

#### Scenario: Compare transcript languages
- **WHEN** a user reviews corresponding English and Traditional Chinese transcript segments
- **THEN** both identify the same original-media time range and remain in the same order

### Requirement: SRT generation is deterministic and valid
The system SHALL generate deterministic SRT output with sequential cue numbers, valid `HH:MM:SS,mmm` timecodes, chronological non-negative intervals, and text encoded as UTF-8.

#### Scenario: Regenerate SRT from unchanged segments
- **WHEN** SRT output is generated more than once from identical transcript and translation segments
- **THEN** the generated bytes are identical

#### Scenario: Generate language-specific SRT
- **WHEN** English and Traditional Chinese segments are available
- **THEN** the English SRT contains English cue text and the Traditional Chinese SRT contains corresponding Traditional Chinese cue text at the original timestamps

#### Scenario: Generate bilingual SRT
- **WHEN** English and Traditional Chinese segments are available
- **THEN** each bilingual cue contains the corresponding English and Traditional Chinese text under one shared original timestamp interval

### Requirement: Summary artifacts are language-labeled
The system SHALL store English and Traditional Chinese summaries as separate UTF-8 text artifacts and MUST NOT present Phase 1 summaries as timestamp-cited, chapter, or key-point outputs.

#### Scenario: Review summaries
- **WHEN** summary generation succeeds
- **THEN** the result identifies each summary language and presents non-empty readable content

### Requirement: Artifacts can be downloaded individually
The system SHALL provide an individual download for each manifest entry using a sanitized descriptive filename and an appropriate content type, and MUST resolve downloads from server-controlled artifact identifiers rather than arbitrary client paths.

#### Scenario: Download an available artifact
- **WHEN** a user requests an artifact listed in a completed job manifest
- **THEN** the system returns that artifact as a download without exposing its internal filesystem location

#### Scenario: Request an unknown or missing artifact
- **WHEN** a client requests an artifact identifier not assigned to the job or whose managed file no longer exists
- **THEN** the system returns a safe not-found response and does not read any other local path
